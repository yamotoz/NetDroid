# 🐍 USO DO VENV (importante!) ═════════════════════════════════════════
# ═════════════════════════════════════════════════════════════════════
#
# Toda vez que abrir um novo terminal para rodar NetDroid:
#
#   1) Entrar na pasta do projeto:
#      cd /caminho/para/NetDroid
#
#   2) Ativar o venv (vai aparecer "(venv)" no prompt):
#      source venv/bin/activate
#
#   3) Confirmar que está usando o python do venv:
#      which python   →  deve mostrar /caminho/NetDroid/venv/bin/python
#
#   4) Rodar (use sudo -E para preservar o venv ao virar root):
#      sudo -E python NetDroid.py --root --auto --god --live
#      sudo -E python NetDroid.py --root --kamikase --live
#
#   5) Para SAIR do venv (volta ao python do sistema):
#      deactivate
#
# ⚠ IMPORTANTE: o `sudo -E` preserva variáveis de ambiente (incluindo PATH
#   do venv). Sem o -E, o sudo usa o python do sistema e perde as deps.
#
# ═════════════════════════════════════════════════════════════════════
# O que o comando completo faz, em ordem:
# ═════════════════════════════════════════════════════════════════════
#
#   1) sudo apt update -y                     → atualiza repositório
#   2) sudo apt install -y <pacotes>          → binários nativos
#   3) python3 -m venv venv                   → cria venv isolado em ./venv/
#   4) source venv/bin/activate               → ativa venv (sem --break-system-packages!)
#   5) pip install --upgrade pip              → pip atualizado dentro do venv
#   6) pip install -r requirements.txt        → instala deps Python no venv
#   7) mkdir -p WordList                      → garante pasta de wordlists
#   8) gunzip rockyou.txt.gz                  → descompacta se necessário
#   9) cp rockyou + fasttrack → WordList/     → wordlists prontas
#

#   python3 python3-pip python3-venv

#   tcpdump arp-scan iw wireless-tools

# ❓ TROUBLESHOOTING:
# ═════════════════════════════════════════════════════════════════════
#
# • "ModuleNotFoundError" mesmo com pip install ok:
#   → você esqueceu de ativar o venv. Rode: source venv/bin/activate
#
# • Após `sudo python ...` dá ModuleNotFoundError:
#   → use `sudo -E python ...` (preserva o venv)
#   → ou rode como: `sudo $(which python) NetDroid.py ...`
#
# • Quer recriar o venv do zero:
#   → deactivate; rm -rf venv; python3 -m venv venv;
#     source venv/bin/activate; pip install -r requirements.txt
#
# • Aireplay-ng pede senha sudo durante kamikase:
#   → rode o NetDroid já como root: sudo -E python NetDroid.py ...
